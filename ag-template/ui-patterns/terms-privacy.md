## Política de Privacidade

### Estrutura Recomendada

```md
# Política de Privacidade

**Última atualização:** [DATA]

## 1. Introdução

[NOME DO SERVIÇO] ("nós", "nosso" ou "nós") valoriza sua privacidade. Esta Política de Privacidade explica como coletamos, usamos e protegemos suas informações pessoais.

## 2. Informações que Coletamos

### 2.1. Informações que Você Fornece

- **Informações de conta:** nome, email, senha
- **Informações de perfil:** foto, biografia, preferências
- **Conteúdo:** [DESCRIÇÃO DO CONTEÚDO]
- **Comunicações:** quando você entra em contato conosco

### 2.2. Informações Coletadas Automaticamente

- **Dados de uso:** páginas visitadas, tempo gasto, ações
- **Dados de dispositivo:** tipo de dispositivo, sistema operacional, navegador
- **Dados de localização:** localização aproximada baseada em IP
- **Cookies e tecnologias similares:** veja nossa Política de Cookies

### 2.3. Informações de Terceiros

Podemos receber informações de terceiros, como:
- Serviços de login social (Google, Facebook)
- Parceiros de análise de dados
- Outras fontes públicas

## 3. Como Usamos Suas Informações

Usamos suas informações para:

- **Fornecer o serviço:** criar e manter sua conta
- **Personalizar experiência:** recomendar conteúdo relevante
- **Comunicar:** enviar atualizações, notificações, respostas
- **Melhorar o serviço:** analisar uso, desenvolver novos recursos
- **Proteger:** detectar e prevenir fraudes, abusos
- **Cumprir leis:** atender obrigações legais

## 4. Compartilhamento de Informações

### 4.1. Quando Compartilhamos

Podemos compartilhar suas informações com:

- **Prestadores de serviço:** hospedagem, análise de dados, email
- **Parceiros de negócio:** com seu consentimento
- **Autoridades legais:** quando exigido por lei
- **Transferência de negócio:** em caso de fusão, aquisição

### 4.2. Quando Não Compartilhamos

Não vendemos suas informações pessoais para terceiros.

## 5. Cookies e Tecnologias Similares

### 5.1. O que São Cookies

Cookies são pequenos arquivos de texto armazenados em seu dispositivo.

### 5.2. Tipos de Cookies que Usamos

- **Essenciais:** necessários para o funcionamento do serviço
- **Funcionais:** lembram suas preferências
- **Analíticos:** ajudam a entender como você usa o serviço
- **Marketing:** usados para publicidade relevante

### 5.3. Gerenciamento de Cookies

Você pode controlar cookies nas configurações do seu navegador.

## 6. Retenção de Dados

Mantemos suas informações enquanto necessário para:

- Fornecer o serviço
- Cumprir obrigações legais
- Resolver disputas
- Fazer cumprir nossos acordos

## 7. Segurança de Dados

Implementamos medidas de segurança para proteger suas informações:

- Criptografia em trânsito (HTTPS)
- Criptografia em repouso
- Controle de acesso
- Monitoramento de segurança

**Importante:** Nenhum método de transmissão pela internet é 100% seguro.

## 8. Seus Direitos

Dependendo de sua localização, você pode ter direitos:

- **Acesso:** solicitar cópia de suas informações
- **Correção:** corrigir informações imprecisas
- **Exclusão:** solicitar exclusão de suas informações
- **Portabilidade:** receber suas informações em formato estruturado
- **Oposição:** opor-se ao processamento de suas informações
- **Restrição:** solicitar restrição do processamento

Para exercer seus direitos, entre em contato: [EMAIL DE CONTATO]

## 9. Transferências Internacionais

Suas informações podem ser transferidas para fora de seu país. Garantimos proteções adequadas para tais transferências.

## 10. Crianças

Não coletamos intencionalmente informações de crianças menores de 13 anos. Se descobrirmos que coletamos, excluiremos as informações.

## 11. Mudanças nesta Política

Podemos atualizar esta Política periodicamente. Notificaremos sobre mudanças significativas.

## 12. Contato

Se tiver dúvidas sobre esta Política, entre em contato:

- Email: [EMAIL DE CONTATO]
- Endereço: [ENDEREÇO]
- Telefone: [TELEFONE]
```

### Checkbox de Aceite

```tsx
// src/components/features/auth/TermsCheckbox.tsx
'use client'

import { useState } from 'react'
import Link from 'next/link'
import { Checkbox } from '@/components/ui/Checkbox'

interface TermsCheckboxProps {
  onAccept: (accepted: boolean) => void
}

export function TermsCheckbox({ onAccept }: TermsCheckboxProps) {
  const [accepted, setAccepted] = useState(false)
  
  const handleChange = (checked: boolean) => {
    setAccepted(checked)
    onAccept(checked)
  }
  
  return (
    <div className="flex items-start gap-2">
      <Checkbox
        id="terms"
        checked={accepted}
        onCheckedChange={handleChange}
      />
      <label htmlFor="terms" className="text-sm text-muted-foreground">
        Eu concordo com os{' '}
        <Link href="/termos" className="text-primary hover:underline" target="_blank">
          Termos de Uso
        </Link>{' '}
        e{' '}
        <Link href="/privacidade" className="text-primary hover:underline" target="_blank">
          Política de Privacidade
        </Link>
      </label>
    </div>
  )
}
```

### Banner de Cookies

```tsx
// src/components/layout/CookieBanner.tsx
'use client'

import { useState, useEffect } from 'react'
import { Button } from '@/components/ui/Button'
import Link from 'next/link'

export function CookieBanner() {
  const [show, setShow] = useState(false)
  
  useEffect(() => {
    const accepted = localStorage.getItem('cookie-consent')
    if (!accepted) {
      setShow(true)
    }
  }, [])
  
  const handleAccept = () => {
    localStorage.setItem('cookie-consent', 'true')
    setShow(false)
  }
  
  if (!show) return null
  
  return (
    <div className="fixed bottom-0 left-0 right-0 z-50 p-4 bg-background border-t">
      <div className="container mx-auto max-w-4xl">
        <div className="flex flex-col md:flex-row items-start md:items-center justify-between gap-4">
          <p className="text-sm text-muted-foreground">
            Usamos cookies para melhorar sua experiência. Ao continuar navegando, você concorda com nossa{' '}
            <Link href="/privacidade" className="text-primary hover:underline">
              Política de Privacidade
            </Link>.
          </p>
          
          <div className="flex gap-2">
            <Button size="sm" onClick={handleAccept}>
              Aceitar
            </Button>
            <Button size="sm" variant="outline" asChild>
              <Link href="/privacidade">Saber Mais</Link>
            </Button>
          </div>
        </div>
      </div>
    </div>
  )
}

// Uso no layout root
// src/app/layout.tsx
import { CookieBanner } from '@/components/layout/CookieBanner'

export default function RootLayout({ children }) {
  return (
    <html>
      <body>
        {children}
        <CookieBanner />
      </body>
    </html>
  )
}
```

## Checklist de Conformidade

### LGPD (Brasil)

- [ ] Política de privacidade em português
- [ ] Consentimento explícito para coleta de dados
- [ ] Opção de revogar consentimento
- [ ] Direitos do titular (acesso, correção, exclusão)
- [ ] Encarregado de dados (DPO) nomeado
- [ ] Registro de operações de dados

### GDPR (Europa)

- [ ] Política de privacidade clara e acessível
- [ ] Consentimento explícito e granular
- [ ] Direito ao esquecimento
- [ ] Portabilidade de dados
- [ ] Notificação de violação em 72h
- [ ] DPIA para operações de alto risco

### CCPA (Califórnia)

- [ ] Aviso de coleta no ponto de coleta
- [ ] Direito de opt-out de venda
- [ ] Direito de saber quais dados são coletados
- [ ] Direito de exclusão
- [ ] Não discriminação por exercer direitos
