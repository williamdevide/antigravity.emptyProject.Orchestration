# Workflow Global — Agente Orquestrador v2

1. **Entrada (Gate G0)**: Validar `0.ideia-inicial.md` na raiz com apoio determinístico (`python scripts/ag-gate.py gate --id g0`). Se faltar informação essencial ou contiver placeholders, pausar e solicitar esclarecimento de forma construtiva.
2. **Entrevista Estruturada**: Conduzir perguntas interativas de alinhamento com a ferramenta nativa `ask_question` para fechar perfil do projeto (1 a 6), stack, abordagem de UI (código puro, Stitch ou mockup) e integrações.
3. **Geração Desacoplada (Gate G1)**: Consolidar as especificações vivas na pasta `docs/` (`docs/prd.md`, `docs/architecture.md`, `docs/design.md` e `docs/security.md`), com rastreabilidade formal `RF-###`, `RNF-###` e `SEC-###`. As diretivas em `.ag-template/documentation/directives/` atuam como templates caso o usuário solicite exportação de prompts para IAs externas.
4. **Auditoria de Ambiente**: Executar `python scripts/ag-gate.py gate --id g1` para checar presença de variáveis necessárias no `.env` sem exibir valores.
5. **Parada Obrigatória de Gate G1**: Apresentar os documentos, tabela de requisitos e riscos residuais. Solicitar aprovação expressa do usuário antes de qualquer escrita de código.
6. **Implementação Incremental (Gate G2)**: Após aprovado o G1, atuar como Tech Lead orquestrador, implementando incrementos atômicos com testes automatizados e acionando subagentes quando necessário (ex: `browser_subagent` para acessibilidade/UI).

Em cada etapa registrar estados reais: `passed`, `failed`, `blocked`, `not-verified` e `not-applicable`. Nunca divulgar segredos, afirmar que integração funciona sem testes reais, nem iniciar implementação sem a aprovação expressa do gate anterior.
