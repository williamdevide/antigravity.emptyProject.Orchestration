# Checklist Pré-voo — Gate G0

Antes de avançar para a geração de especificações em `docs/` (Gate G1):

- [ ] `0.ideia-inicial.md` preenchido na raiz com problema, público e solução claros.
- [ ] Execução com sucesso de `python .ag-template/scripts/ag-gate.py gate --id g0`.
- [ ] Ausência de placeholders como `[Digite o nome do projeto]`.
- [ ] Entrevista interativa via `ask_question` concluída com o usuário.
- [ ] Perfil de projeto definido (1 a 6).
- [ ] Plataforma alvo e abordagem de UI/UX definidas.
- [ ] Integrações obrigatórias para o MVP mapeadas.
