# Prompt — Ideia inicial para projeto e design

Leia somente `0.ideia-inicial.md` na raiz do workspace como entrada de produto. Antes de produzir qualquer arquivo, confirme que não é um template vazio, que há problema, público e objetivo compreensíveis, e que a entrevista `/grill-me` ocorreu. Se faltar informação essencial, pare e solicite-a. Não declare o uso de slash command sem evidência.

Com as informações suficientes, gere `.ag-template/documentation/directives/project/1.ideia-projeto.md` e, se houver UI, `.ag-template/documentation/directives/design/1.ideia-design.md`. Use `project-profiles.md`, `applicability-matrix.md`, `integration-contracts.md` e `risk-catalogue.md` como referências condicionais. Separe fatos, hipóteses, decisões, MVP, futuro e riscos. Não invente API, integração, dados ou design verificados. O `/goal` para os documentos finais deve ficar restrito à especificação e parar em G1.
